What does "deployed" mean?

When a CVE status is deployed, it means a honeypot plugin has been generated and is actively running on the HTTP honeypot (port 8080). Attackers probing that port will see realistic responses that mimic the vulnerable service. For example, a deployed CVE-2024-4577 plugin makes the honeypot respond like a real vulnerable PHP-CGI server — tricking attackers into sending their full exploit payload, which we capture as intelligence.
