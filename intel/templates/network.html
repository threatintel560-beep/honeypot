How Public Exposure Works
  1. 1. ngrok creates a public HTTPS URL pointing to your local port
  2. 2. Censys/Shodan scan all public IPs including ngrok endpoints
  3. 3. Scanners see realistic Apache/nginx/FortiGate — index you as real
  4. 4. Real attackers find you via scanner results and send exploits
  5. 5. Honeypot captures payloads → IOCs extracted → STIX published
Note: ngrok free plan URLs change on restart. For persistent exposure, use a paid plan or deploy to a cloud VM with a static IP.
