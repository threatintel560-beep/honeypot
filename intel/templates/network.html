How It Works

1. ngrok creates a public HTTPS URL pointing to your local port
2. Censys/Shodan scan all public IPs including ngrok endpoints
3. Scanners see realistic Apache/nginx — index you as a real server
4. Real attackers follow scanner results and send exploits
5. Honeypot captures payloads → IOCs extracted → STIX published

⚠️ Note: ngrok free plan URLs change on restart. For persistent exposure, use a paid plan or deploy to a cloud VM with a static IP.
