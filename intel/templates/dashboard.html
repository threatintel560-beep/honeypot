# Deployment Checklist

─────────────────────────────────

1. make up — start all Docker services

2. make expose — ngrok tunnel for public access

3. Poll KEV+NVD to seed CVE database

4. Generate plugins (auto or manual)

5. make reload-http — load new plugins

6. Wait for scanner traffic (5-15 min)

─────────────────────────────────

# Port Mapping

:22 → :2222 (SSH honeypot)

:80 → :8080 (HTTP honeypot)

:8090 (Intel UI + TAXII)

:5601 (Kibana)

─────────────────────────────────

# Security

• Block egress from honeypot containers

• Never expose :8090/:5601 to internet

• Rotate SSH keys: make rotate
